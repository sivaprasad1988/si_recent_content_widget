..  _editor-buttons:

Buttons
=======

:guilabel:`Edit`
    Opens the content element in the editing form. After closing the form you
    return to the dashboard.

:guilabel:`Show page in backend`
    Opens the page in the :guilabel:`Layout` module in the language of the
    content element. The module scrolls to the content element, focuses it
    and highlights it for a short time.

..  note::

    Hidden content elements are not shown in the :guilabel:`Layout` module if
    :guilabel:`Show hidden content elements` is disabled. In this case the page
    opens without scrolling to the element.
